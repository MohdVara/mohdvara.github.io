# NAAE 404 experience v1 — The Unmapped Path

Implemented locally on 23 October 2026. No commit, push, deployment, hosting configuration, analytics or homepage-art changes.

## Result and concept review

Selected **A — The Vanishing Trail**: four staggered ridges, an ochre route that narrows into distant terrain, sparse sedges, a small trail marker and localized semantic fragments. All visible scenery is genuine SVG text; there are no painted paths, raster underlays, portrait assets or studio-engine imports. The left editorial zone remains quieter through composition rather than an opaque card.

Three reproducible, distinct concepts are generated by `node scripts/404-artwork-variants.mjs` into ignored `output/playwright/404-experience-v1/` fixtures. Compare the `stronger-concept-{vanishing,diverging,beyond}-{dark,light}.png` captures:

- **A:** the single winding trace gives the clearest destination/recovery metaphor and remains legible at mobile size. Selected.
- **B — Diverging Paths:** a second branch clearly introduces alternatives, but creates a busier junction competing with the recovery hierarchy. Rejected.
- **C — Beyond the Map:** contour fields dissolve into uncharted negative space. Atmospheric, but the missing trail weakens recognition from a distance. Rejected.

The owner's subsequent visibility feedback is incorporated: stronger sage/teal terrain ink, heavier punctuation glyphs, darker light-mode environmental ink, and larger compact-layout glyphs. Earlier faint-ink captures are preserved under `before-stronger-ink/`. There is no animation or dependency on motion settings.

## Accessible quote and recovery

The sole public quote is **“The map may end here. The possibilities don't.”** It is original UI copy with no famous-person attribution. Candidate C (“When the path disappears, discovery begins.”) was more emphatic than this calm recovery scene; the preferred quote better connects the map to the practical recovery actions.

The quote is a selectable, localized HTML `blockquote > p`, outside the decorative SVG, with a restrained amber rule. It is smaller than the primary heading. The existing `VerticalText` component supports optional Japanese/Chinese vertical presentation. No script is forced into italics. The heading and actions stay horizontal; Arabic uses natural RTL text without reversing the landscape geometry.

There is one `h1`, a labelled `main`, a keyboard skip link, the existing navigation/theme/language controls and existing machine-translation disclosure. Recovery links resolve to the locale home, `#public-engineering`, and `#contact`. All are native anchors with at least 44 px height. The scene is `aria-hidden` as a single decorative subtree and is not the error explanation.

## Rendering and palettes

`notFoundGeometry.ts` defines bounded, seeded glyph positions for all three concepts. `NotFoundLandscape.tsx` renders native SVG text, preserving whole-word shaping and bidi isolation for semantic fragments. It uses the existing locale font registry. Word widths are checked in the browser; no monospace assumption, character splitting, forced text stretching or glyph mirroring is used.

Desktop uses a 1600 × 900 field across the hero width. Compact screens use a separate 420 × 440 composition with fewer, larger glyphs; the scene sits below the recovery links with normal document scrolling. Tablet retains the complete compact scene without shrinking a desktop field. On ultrawide screens the composition remains bounded in height. Forced-colors mode removes decorative art. Static imagery has no CPU animation loop or reduced-motion exception.

Dark palette: teal ridge `#789b8f`, environmental green `#728d79`, contour `#718a72`, trail `#dda658`, semantic text `#b0bc9c`, vegetation `#84966f`, on the site's near-black background. Light palette: sage ridge `#56695b`, terrain `#53644d`, contour `#536149`, sepia trail `#87502c`, semantic ink `#64573a`, vegetation `#666b43`, on warm cream `#faf8f2`. These use shared geometry but distinct ink families, not inversion. Depth is retained through layer-specific opacity; final theme strength is 1.6 dark / 1.9 light with bounded CSS opacity. Punctuation uses weight 600 so small marks remain perceptible.

Paint properties are grouped into SVG `g` elements instead of repeated for every glyph, reducing uncompressed root 404 HTML from the initial implementation's approximately 1.15 MB to approximately 0.25 MB. Full recovery content is server rendered; missing artwork/module delivery does not remove its links.

## Routing and search metadata

The build produces root `dist/404.html` and eleven `dist/{locale}/404.html` fallbacks. Cloudflare Pages walks up the request's directory hierarchy to the nearest 404 document; an existing root 404 disables its implicit SPA fallback. See [Cloudflare Pages serving documentation](https://developers.cloudflare.com/pages/configuration/serving-pages/#not-found-behavior).

The same React 404 component handles unknown client paths. Only that component is lazy loaded, with a useful HTML recovery fallback; SSR injects the resolved component. Route-specific CSS is explicitly linked into static 404 HTML. Missing routes are not silently redirected or added to the known-route list. No rewrite, DNS or Cloudflare setting was added.

All 404 artifacts have `noindex, follow`, localized titles and descriptions, and no canonical, hreflang, `og:url` or WebPage JSON-LD claiming that the missing path exists. None appears in the sitemap. Unknown paths still resolve URL/saved/browser locale through the existing startup system. Locale fonts now load for unknown paths as well as known pages. Switching language preserves the requested missing path, query and fragment; the error title updates with the locale.

Verified against **local Wrangler Pages**, not a live deployment: unknown nested URLs return HTTP 404 with custom recovery; all 108 known sitemap routes return HTTP 200. Eleven localized fallback documents work without JavaScript. An unprefixed missing URL defaults to English in static HTML; a browser can then apply its resolved preference. Without JavaScript a generic static fallback cannot know the full arbitrary requested URL, so its English-original disclosure link uses the static 404 route.
