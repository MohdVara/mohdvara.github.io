# NAAE evolution sources

Reviewed 22 October 2026. Canonical local project name: **Narrative ASCII Art Engine**. The related workspace has no Git repository/tags; file modification dates are not treated as release dates. No engine process, exporter or historical application was run for this task.

## Documented milestones

- v0.1: object masks, protected exact prose, monospaced allocation and SVG text export, supported by `docs/ENGINE-v0.1.md`. No verified v0.1 output is shown.
- v0.2: scene graphs, layered landscapes, regional narrative allocation and physical budgeting, documented in `docs/ENGINE-v0.2.md`.
- v0.3: continuous eligible-cell coverage, independent intensity, measured glyph choices and semantic texture, documented in `docs/ENGINE.md` and actual coverage modules.
- v0.4: separate Pixel-Hybrid style, stepped masks and coherent tile glyph selection, documented in `docs/PIXEL_HYBRID_V0.4.md` and hybrid modules.

These are implementation/artifact identifiers, not an asserted tagged release chronology. Package `0.4.0` and UI ENGINE v0.4 coexist with Organic `rendererVersion: 0.3.0`; Pixel-Hybrid scenes use `0.4.0`.

It is explicitly labeled as such in every locale. It is not claimed to be an original screenshot captured at the time of a v0.2 release. v0.3/v0.4 are saved source exports, copied unchanged. No new historical screenshots or reconstructions were generated.

All selected scenes use seed 1842 and a 1800 × 1012.5 source canvas. PNG preview dimensions differ; framing/settings are disclosed as unsuitable for a controlled quality benchmark. Exact PNG and SVG digests are recorded in `src/data/naae-evolution.json`. Source SVGs retain actual text glyphs and embedded font metadata. The Liberation Mono license is also shipped beside them.

The case-study chunk contains metadata and viewer UI, not the engine. Native radio groups select two stages, a native range controls zoom, focusable viewports permit keyboard scrolling, and a reset restores distance viewing. Missing images retain meaningful text and configuration. SVGs are download-only, and previews are lazy-loaded. Scene mode remains experimental; no physical print validation, rendering speedup or public studio deployment is claimed.
